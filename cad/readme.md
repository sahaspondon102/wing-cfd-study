### CAD Models
This folder contains the .stl & .step files exported from OnShape which was then used in the project (.stl was used, as OpenFOAM's snappy supports .stl natively | .step is included as it retains NURBS). This folder also includes geometric drawings of each wing planform to clarify the design further.
