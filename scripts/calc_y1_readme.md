## Y1 Sizing Script
 calc_y1.py is the y1 (first cell height) calculation script for the addition of boundary layers with the designated y+ target of 1. It includes our aerodynamic
 variables to calculate the boundary layer stack dimensions using standardized formulas.

 For this project, the boundary layer stack is:
 * Layers = 5
 * Growth Rate = 1.2
 * y<sup>+</sup> = 1

 Cell height and stack thickness details can be found in the script.
