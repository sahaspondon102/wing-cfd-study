### Airfoil Files
This folder consists of the .dat & .dxf files (generated using a custom python script, check ../scripts/). This choice of the NACA 2412 airfoil for this project ties to it's frequent use in academic aerodynamic studies, and it's predictable behavior at subsonic speeds. It has a 2% camber & a 12% thickness profile, which means the airfoil is lift generating even at a 0 deg AoA. (For reference, this study was carried out at a 5 deg AoA). Use of this profile & constant span area across all three planforms ensure that the effect of the planform extrusion shape is what drives the differences in the coefficients, not another external factor.
