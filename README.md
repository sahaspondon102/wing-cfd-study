# Comparative Aerodynamic Analysis of Wing Planforms

## Objective

Learn & Investigate the aerodynamic characteristics of different wing planforms using CAD modelling and CFD simulation.

## Wing Types to be investigated

- Rectangular Wing
- Tapered Wing
- Delta Wing
